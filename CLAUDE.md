# Spotify Album Receipt Printer

A two-part system: Python fetches album data from Spotify and generates Arduino source files, which are compiled and uploaded via PlatformIO to print thermal receipts.

## Project Structure

```
/spotify-receipt/
├── CLAUDE.md
├── python/
│   ├── main.py               ← entry point, orchestrates full flow
│   ├── spotify_auth.py       ← OAuth login + token cache
│   ├── spotify_fetch.py      ← album search + track data
│   ├── receipt_builder.py    ← formats data → receipt_data.h + .md archive
│   └── thoughts.py           ← opens editor, archives thoughts
├── arduino/
│   ├── platformio.ini
│   ├── lib/
│   │   └── Adafruit_Thermal/ ← thermal printer library, never modify
│   └── src/
│       ├── main.cpp          ← setup/loop, never modify
│       ├── receipt_print.cpp ← print logic using Adafruit_Thermal
│       ├── receipt_print.h
│       └── receipt_data.h    ← AUTO-GENERATED by Python, never edit by hand
├── receipts/                 ← archived .md receipt per album
└── thoughts/                 ← archived thoughts per album, timestamped
```

## The Handoff Rule — IMPORTANT

`arduino/src/receipt_data.h` is the ONLY file shared between Python and C++.

- Python **writes** it (receipt_builder.py), always fully overwriting it
- C++ **reads** it via `#include "receipt_data.h"`
- **Never manually edit receipt_data.h** — it will be overwritten on next run
- **Never have Python touch** main.cpp, receipt_print.cpp, or receipt_print.h
- **Never have C++ or PlatformIO touch** anything in python/, receipts/, or thoughts/

## Common Commands

```bash
# Run the full Python flow (auth → search → thoughts → preview → generate → upload)
cd python && python main.py

# Upload to Arduino manually (after receipt_data.h is already generated)
cd arduino && pio run --target upload

# Upload and stream build output to terminal (preferred during development)
cd arduino && pio run --target upload --verbose

# Check PlatformIO device port
pio device list
```

## Language Responsibilities

| Layer                | Language      | Responsibility                                      |
| -------------------- | ------------- | --------------------------------------------------- |
| Data & orchestration | Python        | Spotify API, thoughts, file generation, calling pio |
| Printer logic        | C++ (Arduino) | Reading receipt_data.h, driving Adafruit_Thermal    |
| Build & flash        | PlatformIO    | Compiling C++, uploading to board                   |

## receipt_data.h Format

Python always generates this file with this exact structure — do not change the variable names without updating receipt_print.cpp:

```cpp
// AUTO-GENERATED by receipt_builder.py — do not edit
const char* ARTIST      = "Radiohead";
const char* ALBUM       = "OK Computer";
const char* YEAR        = "1997";
const int   TRACK_COUNT = 12;
const char  TRACKS[12][2][32] = {
  {"Airbag",           "4:44"},
  {"Paranoid Android", "6:23"},
};
const char* TOTAL_TIME  = "53:21";
const char* RATING      = "9/10";
const char* FAV_TRACK   = "Exit Music";
const char* NOTES       = "classic";
```

## Thoughts Archiving

- Each run creates a new file: `thoughts/ALBUM-NAME_YYYY-MM-DD.md`
- Files are never overwritten or deleted
- Template fields: Rating, Favorite Track, Notes
- Python reads the file back after the user saves and closes the editor

## Adafruit Thermal Library

Library lives in `arduino/lib/Adafruit_Thermal/`. Key methods used in this project:

```cpp
printer.begin();
printer.justify('C');        // L, C, R
printer.boldOn() / boldOff()
printer.setSize('S');        // S, M, L
printer.println("text");
printer.feed(2);
printer.sleep();
```

Reference: `arduino/lib/Adafruit_Thermal/Adafruit_Thermal.h`

## Spotify API Notes

- Auth: OAuth Authorization Code flow via `spotipy`, token cached to `.cache`
- Scopes needed: none (album search is public endpoint)
- Search returns multiple results — always prompt user to confirm the right album
- Duration comes back in milliseconds — convert to M:SS in receipt_builder.py

## PlatformIO Notes

- Board and port configured in `arduino/platformio.ini`
- Python triggers upload via: `subprocess.run(["pio", "run", "--target", "upload"], cwd="arduino")`
- Stream stdout/stderr so build errors are visible in terminal
- If upload fails, check port with `pio device list`

## What Not to Do

- Do not add code style linting rules here — use a linter
- Do not store the Spotify client secret in code — use a `.env` file
- Do not commit `.cache` (Spotify token) or `.pio/` (build artifacts) to git
- Do not append to receipt_data.h — always fully overwrite it
